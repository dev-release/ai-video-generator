# Spec: providers — одна оболонка для всіх моделей

> Правило власника (CLAUDE.md №8): оболонка навколо моделі описана загально й працює однаково для
> всіх моделей; заміна моделі (Kling → інша) чи тест нової — конфігом, не кодом.

## Три шари

1. **Можливість** (capability) — протокол у `providers/__init__.py`: `script`, `tts`,
   `video`, `lipsync`, `asr`. Вузли графа знають лише протокол.
2. **Транспорт** — один адаптер на (можливість × API): `fal` (черга fal), `anthropic`,
   `fake`, `local`. Адаптер параметризований записом моделі; гілок `if model == …` нема.
3. **Модель** — запис у `src/pipeline/models.yaml`. Нова модель на наявному транспорті = новий
   запис. Новий транспорт = один клас-адаптер + ті самі контрактні тести.

## Схема запису (`registry.ModelSpec`, валідація pydantic при завантаженні)

```yaml
<capability>:
  <name>:                       # ім'я для конфігу: VIDEO_MODEL=<name>
    transport: fal | anthropic | fake | local
    endpoint: "fal-ai/…"        # fal: шлях у черзі; anthropic: model id
    args: {…}                   # шаблон аргументів; змінні — {prompt}, {image_url}, {duration}, …
    reference_endpoint / reference_args   # (video) image-to-video з кадру стику; args — text-to-video.
                                          # reference_args — ПОВНИЙ шаблон для reference_endpoint
    output: "video.url"         # шлях до результату у відповіді (крапки, індекси)
    key: FAL_KEY                # змінна .env; fake — null
    timeout_s: 360
    price: {unit: call|second|1k_chars, usd: 0.084, bill_step: 1, source: URL, checked: YYYY-MM-DD}
    durations_s: [3, …, 15]     # (video) дозволені тривалості; код обирає, модель — ні
    native_audio: true          # (video) модель уміє звук → args МУСЯТЬ його вимикати
    audio_off: {generate_audio: false}
    max_chars: 600              # (tts)
    input_s: [2, 10]            # межі тривалості вхідного медіа (lipsync) — перевірка ДО платного кроку
    price: {…, in_per_mtok: 4, out_per_mtok: 20}   # токенні ціни → фактична вартість з usage
    note: "…"                  # що людина має знати до запуску — UI показує під моделями
```

## Правила — однакові для всіх моделей

| Правило | Де забезпечено |
|---|---|
| Вартість: оцінка з запису моделі, резерв до виклику зі стелями (етап → прогін → доба), повернення, якщо провайдер не списав, фактична ціна | `pricing.cost` → `nodes.produce` → `Tracer.spend` |
| Платна модель без ціни з `source` і `checked` → помилка завантаження реєстру | `registry` |
| Ключ перевіряється preflight до витрат; значення не виводиться | `preflight` читає `spec.key` |
| Таймаут — з запису | транспорт |
| Відео без звуку: `native_audio` → `audio_off` ⊂ `args` | контрактний тест |
| Тривалість відео обирає код з `durations_s` | вузол `video` |
| Результат моделі → файл + sidecar `.url` з хешем файлу (змінився файл → нове завантаження) | транспорт |
| Локальні файли на вхід моделі — офіційне завантаження на CDN (`fal_client.upload_file`), не data URI | транспорт fal |
| Задача відправляється один раз: `fal-job.json` / `fal-result.json`, продовження підхоплює | транспорт fal |
| Платна відправка ретраїться лише на 5xx / «не дійшов»; читання — ще й на таймаутах; 3 спроби | `retry.submit_retry` / `retry.read_retry` у транспорті, не в моделі |
| Ключ перевіряється до резерву (`ready()`); повтор з тим самим входом — з кешу | `nodes.produce` у вузлах |
| Модель не бачить `line` як редаговане поле; звук у фіналі — лише наш | вузли, не модель |
| Обрані моделі записуються в `runs/<id>/models.json`, у трейс і звіт евалів | `graph.Runner` |

## Fake-план — той самий ланцюжок, $0, без мережі й моделей

Fake повторює **кожну ланку** real-режиму, щоб безкоштовний прогін ішов тими самими вузлами й
воротами (кадр з обличчям → кліп без звуку → lipsync під наш аудіо → вимір рота у фіналі). Інакше
lipsync і `sync_check` у fake ніколи не працюють, і їхні помилки видно лише за гроші.

| Можливість | Запис | Що робить (`providers/fake.py`, `providers/puppet.py`) |
|---|---|---|
| script | `fake` | Сценарій з ідеї правилами: стать/вік персонажа — ключові слова ідеї; двоє людей (слова обох статей — «boy … girlfriend»; або «two sisters / brothers / friends») — два персонажі, мовець репліки — стать у тексті перед нею («she replies:»), інакше чергування; місце дії — ідея без реплік (у `style`, спільне для шотів); дія шота — текст перед його реплікою в лапках; крупність — `medium close-up`, потім `close-up`; емоція — з ідеї (whisper…) і пунктуації репліки (`!`, `?`) |
| video | `fake` | **З тексту** (шот 1): кодом (OpenCV) малює персонажа за промптом — волосся, одяг, окуляри, борода з `look`, фон з настрою сцени, крупність з `camera` (`close-up` ×1.3, `extreme close-up` ×1.6, центр — рот) — і оживлює: моргання, повільний наїзд. **З кадру стику** (шот k): той самий кадр, камера плавно їде до крупності `camera`. Рот закритий; без звуку; інший seed (дубль) → інше світло |
| lipsync | `fake` | Рот у кожному кадрі відкривається на RMS-огинаючу **нашого** аудіо шота (`lip.wav`); без звуку |
| face | `fake` | Та сама міра, що в YuNet + LBF, — відкритість рота (`puppet.mouth_openness`), але там, де fake його малює, без детектора |
| tts / asr | `tone` / `echo` | «Бурмотіння» без слів у ритмі репліки: слово — склад гудіння, пауза після розділових знаків, висота за `VoiceProfile`; м'які краї (без клацань). «ASR» чує записане. Слова — Kokoro + whisper (`FAKE_VOICE=kokoro`) |

- Інший seed → інший кліп (дубль зсуває seed на `TAKE_STRIDE`): інакше кадр стику з нового дубля
  збігся б зі старим, апрув за хешем вирішив би, що кадр той самий, і «перегенерувати» мовчки нічого
  не змінило б.
- Геометрія обличчя — у відносних координатах кадру (`puppet.MOUTH`, `EYES`); крупність масштабує її
  навколо рота, тож рот завжди в тій самій точці. Розмір рота fake-відео, fake-lipsync і fake-трекер
  міряють із самого кадру (`puppet.mouth_scale`: довжина лінії закритих губ) — без детектора й без
  передачі параметрів між етапами, як і в реальних моделях.
- Два шоти мусять бути видно: шот 2 починається з кадру стику (перехід без стрибка), далі камера
  їде до іншої крупності — монтаж видно, контекст не губиться (запит власника 2026-10-01).
- Fake-адаптер обирає фікстуру **за записом реєстру** (`fake.fixture(spec)`), без гілок у вузлах.
  `passthrough` (lipsync) і `none` (face) — фікстури юніт-тестів: швидкі, без рендеру.
- Намальований рот синхронний зі звуком **за побудовою** — еталон для калібрування `SYNC_*`
  (spec sync.md, «Відкриті питання»).

## Як додати / замінити модель

Процедура — скіл `add-provider` (тут не дублюється, щоб не розходилась).

## Перевірка

`tests/test_puppet.py`: fake-план — кадр з персонажем за `look`, кліп потрібної тривалості без
звуку, рот відкритий у мові й закритий у тиші, `sync_check` на fake-прогоні має обличчя й вердикт.
`tests/test_registry.py`: для **кожного** запису — схема, ціна з джерелом (платні), ключ, таймаут,
шаблон аргументів рендериться з типовими змінними, результат витягується за `output` з
прикладу відповіді, відео з `native_audio` вимикає звук. Адаптери — на моках транспорту для
кожного запису свого транспорту.
