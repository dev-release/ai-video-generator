# Spec: approve_script — апрув сценарію й промптів відео

> Запит власника 2026-10-01: «на апрув сценарій після написаного промпта, що піде для генерації
> відео». Людина бачить не опис, а **дослівно** ті промпти, які піде в модель відео.

## Призначення
Точка людського контролю перед першим платним відео: сценарій (персонажі, голос, кожен шот) і
план відео — для кожного шота промпт, звідки старт (текст / кадр стику), тривалість, ціна. Відео —
найдорожчий етап; сценарій і голос до нього коштують центи.

## Вхід
`state.script`, `state.casting`, `state.voices` (вікно мови й паузи → у промпті),
`video.plan(state, ctx)`.

## Вихід
- `VideoPlan` (`schema.py`) → `runs/<id>/video_plan.json`: `{model, negative_prompt, cost_usd,
  shots: [ShotPlan{shot_id, character_id, line, delivery, start, source_shot, shot_s, clip_s,
  prompt}]}`.
- `state.plan_sha` — хеш апрувнутого плану; `approvals.json["plan"] = {sha, by}`.

## Інваріанти
- **Апрувнуте = надіслане.** Промпти плану й промпти, які `video` віддає моделі, рахує одна функція
  `video.plan`; `video` не генерує нічого, якщо хеш поточного плану ≠ `state.plan_sha`
  (`PlanNotApproved`) — змінився план після апруву → новий апрув.
- Апрув прив'язаний до хешу плану (`approvals.json`): той самий план удруге не питаємо (перезапуск,
  новий дубль lipsync); новий план (новий сценарій, новий дубль голосу змінив вікно мови) — питаємо.
- Стоїть **після** `voice_check`: промпт містить вікно мови й паузи з готового wav.
- «Переписати» = новий дубль сценарію (`runmemo.bump_take(run, "script", "script")` → новий ключ
  кешу й платний виклик), далі голос → ворота аудіо → знову апрув. Репліки (`line`) не змінюються —
  їх вставляє код із `Brief`.
- Без `--review` / галочки в UI — апрув автоматичний (`by: auto`), без зупинки (PDF: одна команда).

## HITL
LangGraph `interrupt({"kind": "approve_script", "script", "plan", "next_cost_usd"})`. Відповідь —
`{"script": "approve" | "regenerate"}`; інше → та сама пауза з поясненням в `error`
(`nodes.ask_human`), API — 422. CLI: план друкується, `[a]pprove /
[r]ewrite / [q]uit`. UI: таблиця шотів із промптами, кнопки «✓ Approve» / «↻ Rewrite script».

## Детерміноване vs модель
Усе — код: промпт збирається з полів сценарію (`scene_prompt`, `motion_prompt`), тривалості — з
`timeline`, ціна — з `models.yaml`. Модель написала лише поля сценарію.

## Перевірка
`tests/test_approve_script.py`: пауза до будь-якого відео з промптами плану; промпти плану ==
надіслані моделі; «переписати» → новий виклик сценарію й знову апрув; той самий план удруге не
питаємо; змінений план без апруву → `PlanNotApproved`; auto → без паузи.

## Вартість і час
$0. У паузі `next_cost_usd` = відео + lipsync усіх шотів (lipsync — консервативно для всіх: обличчя
до відео невідоме).

## Помилки
- Невідоме рішення → та сама пауза з `error`; прогін не застрягає в помилці.
- Ідемпотентність: ключ апруву = хеш `VideoPlan`.

## Відкриті питання
- Правка промпту руками в паузі (зараз — лише «переписати» весь сценарій).
