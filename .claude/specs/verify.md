# Spec: verify — ворота дослівності

## Призначення
Довести, що у **фінальному файлі** звучить репліка слово в слово. Серце завдання (CONTEXT §3).

## Вхід
`state.final.path`, `state.script.shots[].line` (еталон).

## Вихід
`AsrCheck` → `runs/<id>/asr_check.json`:
`{expected, heard, expected_norm, heard_norm, wer, passed, attempt, model, diff: [...]}`

## Алгоритм
1. ffmpeg: аудіо з `final.mp4` → 16 кГц mono wav.
2. ASR **через API**: whisper на fal (`fal-ai/whisper`, `language="en"`, `chunk_level="word"`,
   $0/с — https://fal.ai/models/fal-ai/whisper, 2026-09-29). Незалежність від TTS-провайдера
   (Kokoro) — навмисна; API замість локальної моделі — щоб у рецензента на будь-якій машині
   працювало однаково (CONTEXT «Рішення»). Локальний faster-whisper — лише опційний extra `local`.
3. Еталон = рядки всіх шотів у порядку таймлайну, через пробіл.
4. Обидві сторони → **один** канонізатор `normalize()` (у копії; `line` не чіпається).
5. `wer = jiwer.wer(expected_norm, heard_norm)`; `passed = wer == 0`.

## Канонізатор `normalize(text) -> str` — правила (кожне покрите тестом)
1. Unicode NFKC; «розумні» лапки/апострофи → `'` `"`; тире/дефіс → пробіл.
2. Нижній регістр.
3. Числа → слова (`num2words`, en): `3` → `three`; `21st` → `twenty first`;
   `1,000` → `one thousand`; `3.5` → `three point five`; `50%` → `fifty percent`;
   `$5` → `five dollars`. Дефіси з num2words (`twenty-one`) → пробіл.
4. `&` → `and`.
5. Уся пунктуація видаляється, **крім** апострофа всередині слова (`don't`, `i'm` лишаються).
6. Пробіли схлопуються, trim.
Скорочення (`I'm` ↔ `I am`) **не** розгортаються: TTS читає написане, whisper пише почуте —
розбіжність тут означає справжню розбіжність.

## Інваріанти
- Звіряється лише фінальний mp4, ніколи проміжний wav.
- Поріг жорсткий: WER == 0. Жодного «майже».
- ASR слухає **копію** звуку фіналу з тишею `ASR_PAD_S` (0.5 с) до й після: Whisper губить перше
  слово, якщо мова починається в перші ~0.4 с файлу (евал 07-betrayal, 2026-10-01). Ролик не
  змінюється, поріг той самий.
- Модель не вирішує, чи пройдено: рішення — порівняння рядків у коді.

## Реакція на провал
`passed=False` → прогін **зупиняється** (`failed_verify`, код ≠ 0), `final.mp4` лишається з
`asr_check.passed=false`, у консолі й UI — diff. **Автоматичного перегенерування нема**: голос
уже пройшов ворота аудіо (`voice_check`) до відео, а новий голос тягнув би нове відео й lipsync —
до $1–2 за примху ASR (аудит бюджету 2026-09-30). Людина вирішує явно: новий дубль голосу шота
(UI «перегенерувати» / `--regen voice:sN`).

## Перевірка
- Юніт-тести `normalize()` на кожне правило + ідемпотентність `normalize(normalize(x)) == normalize(x)`.
- Тест воріт: fake-ASR повертає рядок із пропущеним словом → `passed=False`, стоп з diff без нових
  платних викликів (`tests/test_graph.py`).
- Інтеграційний: провайдер ASR на моках транспорту (`tests/test_providers.py`); живий — smoke.
- Зайве слово, що прозвучало (`whispers I never wrote this`), → `passed=False`: це справжня
  розбіжність, не привід чистити такі слова в `normalize()`.

## Вартість і час
$0 (fal whisper), кілька секунд на запит.

## Помилки
- ASR 5xx/таймаут → загальне правило; 4xx → стоп. Ворота ніколи не пропускаються.
- Порожній транскрипт → `passed=False` (тиша у фіналі — баг assemble/voice).
