# wrap-up — «готово» і передача стану наступній сесії

Наступна сесія знає лише те, що у файлах: `PROGRESS.md` вантажиться в контекст автоматично
(`CLAUDE.md` + хук SessionStart). Хук Stop не дасть завершити відповідь, якщо код змінено після
останнього зеленого `make check`.

## Чекліст (по порядку)

1. **Звірка з задачею.** Зміна не суперечить CONTEXT («Рішення власника»; §3 — репліка звучить
   дослівно у відео; §13 — «готово») і PDF, Ч.4: «одна команда / один виклик — на виході
   відеофайл». Перевірка етапу — прогін графа, а не окремий інструмент (CLAUDE.md).
2. **Свій дифф очима.** `git status --short`, `git diff --stat`, потім дифф змінених файлів. Лише
   заплановане: без налагоджувального виводу, закоментованого коду, артефактів `runs/`, ключів.
   Видалене чи перейменоване — `grep -rn "<старе ім'я>" src tests evals ui/src .claude README.md`
   нічого не знаходить.
3. **Документи в лад.** Зміна торкнулась описаного в spec, README, CLAUDE.md чи скілі → оновити.
   Одне правило — одне місце; в інших — посилання.
4. **`make check` зелений** — лінт, збірка UI, усі тести (приймальні, браузерні, звірка документів,
   хуки), евал на справжній мові. Червоне → лагодити причину; `--no-verify`, `skip`, `xfail` без
   пояснення — ні. Пропущений тест (`-rs`) — сказати власнику. `pass_rate` евалу не нижчий за
   попередній звіт тих самих умов в `evals/reports/` — інакше це регресія, сказати.
5. **Те, що бачить людина** (UI, медіа, повідомлення CLI) → браузерний або приймальний тест на саме
   це (видимість — `to_be_in_viewport`, не лише наявність) і сценарій власника: `make ui` з
   `FAKE_VOICE=kokoro`, headless Chrome, «+ New run» → результат видно без прокрутки й
   звучить дослівно; або одна CLI-команда.
6. **`PROGRESS.md`:** виконане → «Зроблено» (коротко, з назвами файлів); «В роботі / блокер» —
   лише те, що реально блокує, з варіантами; «Далі» — наступний конкретний крок першим рядком;
   «Потрібно від власника» — рішення, які агент ухвалювати не може.
7. Помилка AI (твоя чи попередньої сесії), яку виправили → скіл `log-ai-mistake`.
8. **Не комітити** (CLAUDE.md №7). Звіт власнику: що зроблено; як перевірено — команда і
   результат, номер прогону, очікувано/почуто, WER, тривалість, $; **що зміниться на слух і на
   око** (звук, картинка, тексти UI) — окремим рядком (AI_LOG 2026-09-30, тон-заглушка); що далі;
   «зміни не закомічені».
